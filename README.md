## 🚀 Objetivo

Propósito do projeto:

- Foi observado que existem diversas ferramentas que auxiliam na produtividade das pessoas no dia a dia. No entanto, muitos acabam deixando de usá-las por achar muitas vezes ferramentas pouco intuitivas e sem senso de progresso.  Muitas crianças e adolescentes não sentem dificuldades em jogar, mas fazer tarefas do dia a dia, muitas vezes parece massante.
Pensando nessa parcela da população que tem dificuldade de se concentrar numa atividade, decidi desenvolver um sistema como se fosse um joguinho Pokémon. Nele, o usuário consegue se divertir treinando seus pokémons para ficarem fortes para batalhas, ao mesmo tempo que conclui suas tarefas diárias.

## 📦 Instalação

### 1. Clone o repositório

```bash

git clone https://github.com/joaonevescampos/pokegym.git

```
Mude para sua pasta

```bash
cd pokegym
```

Instale as dependências:
```bash
npm install
```

Rode o projeto:
```bash
npm run dev
```
